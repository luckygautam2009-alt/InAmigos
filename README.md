# InAmigos Foundation Website

A modern, premium, and feature-rich website for the **InAmigos Foundation** NGO. This application is designed to showcase the organization's mission, impact, programs, and events, while facilitating connection and support from donors and volunteers.

## 🚀 Live Demo 
- https://in-amigos-lilac.vercel.app/

---

## ✨ Features

- **🏠 Dynamic Landing Page:** Beautiful hero section with call-to-actions, core mission statement, and key navigation.
- **📊 Animated Counters:** Real-time animated counts of volunteers, beneficiaries, campaigns, and funds raised.
- **ℹ️ Detailed About Section:** Deep dive into the NGO's history, vision, values, and leadership.
- **📚 Dedicated Programs Page:** Categorized educational, environmental, and healthcare programs.
- **📈 Impact Tracking:** Real-world metrics and stories showcasing the concrete change brought by the NGO.
- **📅 Events & Gallery:** Interactive calendar of upcoming events and a rich media gallery of past initiatives.
- **💬 Testimonials:** Stories and quotes from beneficiaries, donors, and volunteers.
- **✍️ Blog Platform:** Educative articles, news, and updates from the field.
- **📞 Dynamic Contact Form:** Reach out for collaborations, queries, or volunteer applications.

---

## 🛠️ Tech Stack

- **Core:** React, TypeScript, HTML5
- **Styling:** Tailwind CSS, Lucide React (Icons)
- **Build System:** Vite
- **Development Tooling:** PostCSS, TypeScript compiler

## 💻 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18+) and **npm** (or **pnpm** / **yarn**) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/luckygautam2009-alt/InAmigos.git
   cd InAmigos
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
